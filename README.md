# SoundBunker plug-in downloads

Installers for the SoundBunker plug-ins (macOS 12+ on Apple silicon and Intel; Windows 10/11 x64).
Each plug-in runs as a free 14-day trial; a licence key from **https://www.soundbunker.pt/plugins.html** unlocks it.
The Armoury (11 effects) is free with a key from the same page.

Download the installers from the [Releases](../../releases) page. macOS installers are signed and notarized by Apple.

| Plug-in | What it is |
| --- | --- |
| SoundBunker Armoury | 11 mix and master effects (free) |
| NUCLEAR | Wavetable synthesiser |
| NAPALM | Virtual analogue synthesiser |
| SHRAPNEL | Drum machine and sample instrument |
| FALLOUT | Extreme saturation |
| SENTINEL | Precision mastering console |
